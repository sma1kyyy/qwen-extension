# prisma-ui

## Назначение

Используйте этот skill, когда пользователь просит создать, переписать или дополнить интерфейс на **Prisma UI**:

- страницы и виджеты на React/JSX;
- формы, карточки, таблицы, модальные окна, dashboard-блоки;
- исправление UI-кода так, чтобы он использовал компоненты Prisma UI вместо `div`, `span` и произвольной верстки;
- генерация примеров, которые можно сохранить в файл через другие skills или вернуть пользователю в ответ.

## Обязательные источники внутри skill

Перед генерацией UI прочитайте и примените:

1. `docs/components.md` — каталог компонентов, props и правила композиции.
2. `docs/examples.md` — эталонные запросы и ответы.
3. `prompts.md` — системные правила поведения агента при генерации Prisma UI.

Если пользователь просит компонент, которого нет в `docs/components.md`, не выдумывайте API. Используйте ближайший документированный компонент или задайте уточняющий вопрос.

## Алгоритм работы

### Шаг 1: Определите задачу пользователя

Классифицируйте запрос:

- `component` — отдельный компонент: кнопка, input, карточка, modal;
- `form` — форма логина, регистрации, фильтра, профиля;
- `page` — полноценная страница: каталог, dashboard, landing, admin screen;
- `refactor` — переписать существующий JSX на Prisma UI;
- `example` — показать пример использования компонента.

### Шаг 2: Соберите недостающие требования

Задавайте уточняющие вопросы только если без них нельзя сделать корректный UI. Если детали не указаны, используйте безопасные defaults:

- React + JSX;
- функциональные компоненты;
- импорт компонентов из `@prisma-ui/react`;
- статичный UI без состояния, кроме случаев, где интерактивность обязательна (`Modal`, `Tabs`, `Toast`, раскрывающиеся меню);
- доступные подписи на русском, если пользователь пишет по-русски.

### Шаг 3: Выберите компоненты Prisma UI

Используйте семантические компоненты вместо сырой HTML-разметки:

- действия: `Button`, `IconButton`;
- поля: `Input`, `Textarea`, `Select`, `Checkbox`, `RadioGroup`, `Switch`;
- структура: `Page`, `Section`, `Stack`, `Inline`, `Grid`, `Card`;
- текст: `Heading`, `Text`, `Link`;
- обратная связь: `Alert`, `Badge`, `Spinner`, `Toast`;
- overlay: `Modal`, `Overlay`, `Drawer`, `Tooltip`, `Popover`;
- данные: `Table`, `Pagination`, `EmptyState`.

### Шаг 4: Сгенерируйте код

Код должен быть:

- самодостаточным;
- с корректными импортами;
- готовым для копирования в `.jsx` или `.tsx` файл;
- без несуществующих props;
- с минимальным количеством `div`/`span` только там, где это невозможно заменить компонентами Prisma UI;
- с доступными labels, `aria-label`, `htmlFor`, `id` для форм и интерактивных элементов.

### Шаг 5: Формат ответа

Если пользователь просит «только код» — верните один блок кода без пояснений.

Если пользователь просит объяснить решение — верните:

1. краткое описание подхода;
2. JSX/TSX код;
3. список использованных компонентов Prisma UI.

### Шаг 6: Интеграция с другими skills

#### Интеграция с generate-page

Если пользователь просит сохранить страницу:

1. Сгенерируйте полный JSX-код компонента
2. Передайте его в skill `generate-page` для сохранения в папку `pages/`
3. Укажите имя файла без расширения (например: `profile-page`)

#### Интеграция с create-layout

Если пользователь просит создать layout:

1. Сгенерируйте полный JSX-код layout-компонента
2. Передайте его в skill `create-layout` для сохранения в папку `layouts/`
3. Укажите имя файла без расширения (например: `admin-layout`)

#### Интеграция с init-ui-project

Если проект не инициализирован:

1. Сначала запустите skill `init-ui-project`
2. Дождитесь создания структуры проекта
3. Затем приступайте к генерации UI

### Шаг 7: Проверка качества

Перед финальным ответом проверьте:

- [ ] Есть импорт из `@prisma-ui/react`;
- [ ] Button/Card/Text и другие компоненты используются из Prisma UI;
- [ ] Форма имеет label и понятные `name`/`id`;
- [ ] Modal обернут в `Overlay` согласно правилам из `docs/components.md`;
- [ ] Нет случайных компонентов из Material UI, Ant Design, CoreUI или shadcn/ui;
- [ ] JSX валиден и экспортирует компонент;
- [ ] Код готов для копирования в файл без правок.
