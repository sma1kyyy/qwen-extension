# Prisma UI Skill

## Описание

`prisma-ui` — skill для Qwen Agent, который помогает генерировать интерфейсы на базе **Prisma UI**. Skill не дообучает модель и не реализует нового агента с нуля. Он предоставляет структурированную документацию, правила и примеры, чтобы LLM мог стабильно писать корректный React-код с компонентами Prisma UI.

## Что умеет skill

- Генерировать React/JSX UI на Prisma UI по текстовому запросу.
- Подбирать правильные компоненты библиотеки вместо сырой HTML-разметки.
- Создавать типовые интерфейсы: карточки, формы, модальные окна, таблицы, dashboard-блоки.
- Возвращать готовый код с импортами из `@prisma-ui/react`.
- Объяснять, какие компоненты были использованы и почему.
- Передавать готовый код другим skills для записи в файлы или дальнейшей обработки.

## Когда использовать

Используйте `prisma-ui`, если пользователь просит:

- «Сделай форму логина на Prisma UI»;
- «Собери карточку товара с кнопкой Купить»;
- «Покажи модальное окно подтверждения»;
- «Перепиши этот JSX на Prisma UI»;
- «Сгенерируй страницу dashboard/admin/catalog/profile».

## Базовые правила генерации

1. **React first:** генерируйте функциональные React-компоненты.
2. **Prisma UI only:** импортируйте UI-компоненты из `@prisma-ui/react`.
3. **No random libraries:** не используйте Material UI, Ant Design, CoreUI, Bootstrap или shadcn/ui, если пользователь явно не попросил.
4. **Semantic components:** предпочитайте `Page`, `Section`, `Card`, `Stack`, `Grid`, `Text`, `Heading`, `Button` вместо `div` и `span`.
5. **Accessible UI:** для форм используйте `label`, `id`, `name`, `aria-label` и понятные тексты ошибок.
6. **State only when needed:** не добавляйте `useState`, если интерфейс может быть статичным. Для `Modal`, `Tabs`, `Toast` и управляемых элементов состояние допустимо.
7. **Ready-to-copy code:** возвращайте полноценный компонент с импортами и `export default`.

## Минимальный пример

Запрос пользователя:

```text
Сделай карточку товара с названием, ценой и кнопкой "Купить" на Prisma UI
```

Ожидаемый ответ агента:

```jsx
import { Badge, Button, Card, Heading, Stack, Text } from '@prisma-ui/react'

const ProductCard = () => {
  return (
    <Card padding="lg" radius="lg" shadow="md">
      <Stack gap="md">
        <Badge tone="success">В наличии</Badge>
        <Stack gap="xs">
          <Heading level={3}>Prisma Hoodie</Heading>
          <Text tone="muted">Мягкое худи для команды разработки</Text>
        </Stack>
        <Text size="xl" weight="bold">4 990 ₽</Text>
        <Button variant="primary" size="md">Купить</Button>
      </Stack>
    </Card>
  )
}

export default ProductCard
```

## Как проверить skill вручную

1. Откройте CLI агента.
2. Попросите: `Сделай карточку товара с названием, ценой и кнопкой "Купить" на Prisma UI`.
3. Проверьте, что ответ содержит:
   - импорт из `@prisma-ui/react`;
   - компоненты `Card`, `Button`, `Text` или `Heading`;
   - полноценный JSX-компонент;
   - минимум сырой HTML-разметки.

### Шаг 1: Инициализация проекта (если нужно)

```bash

```

### Шаг 2: Генерация UI

```bash
# Запустите skill prisma-ui
# Опишите что нужно создать
# Получите готовый JSX-код
```

### Шаг 3: Сохранение в файл

```bash
# После генерации кода подтвердите сохранение
# Укажите путь к файлу (pages/имя.jsx или layouts/имя.jsx)
# Файл будет создан в соответствующей папке
```

## Что делать, если в проекте появится реальный API Prisma UI

Если команда предоставит официальную документацию или исходники компонентов, обновите в первую очередь:

1. `docs/components.md` — точные props и ограничения;
2. `docs/examples.md` — примеры с актуальным API;
3. `prompts.md` — правила импорта, naming и композиции.

До появления официальной документации этот skill фиксирует контракт, понятный агенту, чтобы генерация была предсказуемой и единообразной.

## Интеграция с другими skills

### С generate-page

Для сохранения страниц в папку `pages/`:

1. Сгенерируйте полный JSX-код компонента
2. Подтвердите сохранение с пользователем
3. Передайте код в skill `generate-page` с указанием имени файла

### С create-layout

Для создания reusable layout-компонентов:

1. Сгенерируйте полный JSX-код layout-компонента
2. Подтвердите сохранение с пользователем
3. Передайте код в skill `create-layout` с указанием имени файла

### С init-ui-project

Для создания новой структуры проекта:

1. Запустите skill `init-ui-project`
2. Дождитесь создания структуры (pages/, docs/, ui-project.xml)
3. Приступайте к генерации UI через skill `prisma-ui`
