# list-layouts

## Инструкция

**Ищи ТОЛЬКО в папке `layouts/` в корне текущего проекта. Никаких других директорий.**

### Шаг 1: Проверка папки layouts/

Проверь существование папки `layouts/` в текущей рабочей директории (там где находится `ui-project.xml`).

- Если папка `layouts/` **не существует** или **пуста** — верни:
  ```
  Layouts не найдены.
  ```
- Если файлы `.jsx` есть — перечисли их названия без расширения.

### Шаг 2: Вывод списка

```
Доступные layouts:
1. {название} — {тип: sidebar/header/footer/комбинированный}
2. ...
```
