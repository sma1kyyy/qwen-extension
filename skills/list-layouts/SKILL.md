# list-layouts

## Инструкция

Ваша задача: показать список всех доступных layout'ов в проекте

### Шаг 1: Поиск layout'ов

- Проверьте наличие папки `layouts/` в корне проекта
- Если папка не существует — сообщите: "Папка layouts не найдена. Сначала создайте layout с помощью skill 'create-layout'"
- Если папка существует — прочитайте все файлы `.jsx` внутри

### Шаг 2: Отображение списка

Покажите пользователю список layout'ов в формате:
```
Доступные layout'ы:
1. {имя файла без .jsx} — {описание на основе содержимого или "без описания"}
2. ...
```

Если layout'ов нет — сообщите: "В папке layouts нет доступных layout'ов. Создайте первый layout с помощью skill 'create-layout'"

### Шаг 3: Дополнительная информация (опционально)

При необходимости можно показать краткое описание каждого layout'а на основе его содержимого (тип layout'а, наличие навигации и т.д.)
